Relay Agent Setup

To use Remote Relay mode, run the relay agent on a computer at the radio site (same LAN as the FlexRadio):

python relay_agent.py --radio-ip 192.168.1.100 --api-key YOUR_SECRET_KEY

Options:

  • --radio-ip — FlexRadio IP on the LAN (required)
  • --api-key — shared secret key (required, must match above)
  • --radio-port — radio TCP port (default: 4992)
  • --host — relay bind address (default: 0.0.0.0)
  • --port — relay HTTP port (default: 5001)
ZeroTier Setup Guide

How it works:

  1. Create a ZeroTier network at my.zerotier.com
  2. Install ZeroTier on the FlexRadio PC and join the network — keep this node always authorized
  3. Each club member installs ZeroTier and joins the same network
  4. Members enter their ZeroTier Node ID when they register (or admin adds it later)
  5. When a member's time slot starts, the scheduler authorizes their node on the network
  6. When the slot ends, the scheduler deauthorizes their node
  7. Members point SmartSDR at the FlexRadio's ZeroTier IP during their slot
Important: Make sure the FlexRadio host node and the scheduler server node are always authorized on the ZeroTier network (not managed by the scheduler). Only add club member node IDs to user accounts — the scheduler will manage their authorization.
